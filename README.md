# Bulbul Words (بلبل الكلمات)

An Arabic and English early vocabulary app for toddlers, built for Android with Jetpack Compose.

## Features
- Bilingual early vocabulary learning (Arabic and English)
- Simple, child-friendly Jetpack Compose UI

## Build
- Requirements: JDK 17+ and Android Studio (or just the Android SDK)
- Debug build: `./gradlew assembleDebug`
- Release signing reads `keystore/keystore.properties`, which is not included in this repository. Without it, use the debug build.
